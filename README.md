# CIT300 Hospital EMS (Emergency Management System)

A Java-based Hospital Emergency Management System for managing patient records, appointments, medical staff, and emergency services.

## Project Structure

```
CIT300-Hospital-EMS/
├── src/
│   └── main/
│       └── java/
│           └── hospital/
└── README.md
```

## Getting Started

All Java source files and packages should be placed inside `src/main/java/hospital/`.

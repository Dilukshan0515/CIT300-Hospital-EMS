# Mini Hospital Emergency Management System

## Overview
A Java console application built for CIT300 - Data Structures and Algorithms 
(Individual Mid Assignment). The system simulates hospital operations including 
patient registration, emergency queue management, treatment history tracking, 
and patient visit history — each implemented using a specific data structure 
built from scratch (no built-in Java collection classes for these core parts).

## Data Structures Used
| Feature                  | Data Structure       | Status       |
|---------------------------|----------------------|--------------|
| Patient Records            | Binary Search Tree   | ✅ Completed |
| Emergency Patient Queue    | Queue (custom)       | 🔲 Pending   |
| Treatment History          | Stack (custom)       | 🔲 Pending   |
| Patient Visit History       | Singly Linked List   | 🔲 Pending   |

## Features Implemented So Far

### Patient Records (Binary Search Tree)
- Insert a new patient (keyed by unique Patient ID)
- Search for a patient by ID
- Delete a patient by ID
- Display all patients in ascending order of ID (in-order traversal)

Each patient record stores: Patient ID, Name, Age, Contact Number, Medical Condition.

The system runs through an interactive console menu that prompts the user for 
input rather than using hardcoded data.
